B2.5 Procesamiento de archivos

Pregunta guía

¿Cómo pueden los programas leer, escribir y almacenar información en archivos para conservar datos más allá de una sola ejecución?

Introducción

En los temas anteriores hemos trabajado con variables, estructuras de datos, algoritmos y estructuras de control. Sin embargo, existe una limitación importante en muchos programas sencillos: la información solo permanece disponible mientras el programa está en ejecución. Cuando el programa termina, los datos almacenados en memoria se pierden.

Esto puede ser suficiente en ejercicios muy simples, pero no en aplicaciones reales. Por ejemplo, una aplicación puede necesitar:

  • guardar las notas de los estudiantes
  • almacenar una lista de tareas
  • registrar usuarios
  • leer datos previamente guardados
  • generar informes o listados

Para resolver este problema, los programas utilizan archivos. Un archivo permite almacenar información de manera permanente en un dispositivo de almacenamiento, como el disco duro o la memoria del ordenador.

El procesamiento de archivos consiste en trabajar con esos datos almacenados: abrir archivos, leer su contenido, escribir información nueva, modificarla o utilizarla dentro del programa.

En este tema estudiaremos:

  • qué es un archivo en informática
  • por qué es útil trabajar con archivos
  • cómo se realiza la lectura de archivos
  • cómo se realiza la escritura de archivos
  • cómo se relaciona el procesamiento de archivos con el almacenamiento de datos

El objetivo es que el alumnado comprenda cómo los programas pueden conservar información más allá de la ejecución inmediata y cómo esto amplía enormemente sus posibilidades.

Explicación detallada

¿Qué es un archivo?

Un archivo es una unidad de información almacenada de manera permanente en un dispositivo. En términos sencillos, un archivo es un conjunto de datos guardado con un nombre y un formato determinado.

Ejemplos cotidianos de archivos son:

  • un documento de texto
  • una imagen
  • una hoja de cálculo
  • un archivo de audio
  • un archivo de datos generado por un programa

En programación, muchas veces trabajamos con archivos de texto o archivos de datos sencillos que contienen información organizada para ser leída o modificada por el programa.

Idea clave

La gran diferencia entre una variable y un archivo es que:

  • la variable almacena información temporalmente durante la ejecución del programa
  • el archivo almacena información de forma persistente, incluso después de cerrar el programa

¿Por qué es importante el procesamiento de archivos?

El procesamiento de archivos es importante porque permite que un programa:

  • recupere datos guardados anteriormente
  • conserve información entre distintas ejecuciones
  • genere registros o informes
  • trabaje con grandes cantidades de datos sin introducirlos manualmente cada vez
  • almacene resultados para utilizarlos más adelante

Sin archivos, muchos programas serían poco útiles en la práctica, porque siempre comenzarían desde cero.

Ejemplo

Imagina un programa que permite guardar las notas de una clase. Si las notas solo se almacenan en variables, al cerrar el programa se perderán. Si en cambio se guardan en un archivo, podrán recuperarse más tarde.

Lectura de archivos

La lectura de archivos consiste en abrir un archivo existente y obtener la información almacenada en él para que el programa pueda utilizarla.

Por ejemplo, un programa puede leer:

  • una lista de nombres
  • un conjunto de calificaciones
  • una serie de números
  • datos de configuración
Proceso general de lectura
  1. abrir el archivo
  2. leer su contenido
  3. cerrar el archivo
Ejemplo conceptual

Supongamos que existe un archivo llamado notas.txt con el contenido:

7
8
6
9
5

Un programa podría leer ese archivo para recuperar las notas y calcular la media.

Ejemplo en Python
archivo = open("notas.txt", "r")
contenido = archivo.read()
archivo.close()

print(contenido)

En este ejemplo:

  • open("notas.txt", "r") abre el archivo en modo lectura
  • read() lee el contenido
  • close() cierra el archivo
Lectura línea a línea

A veces no interesa leer todo el archivo de una vez, sino procesarlo línea por línea.

archivo = open("notas.txt", "r")

for linea in archivo:
    print(linea)

archivo.close()

Esto resulta útil cuando el archivo contiene varios registros o varias filas de datos.

Ventajas de leer línea a línea
  • permite procesar archivos grandes de forma más ordenada
  • facilita el tratamiento individual de cada dato
  • ayuda a estructurar mejor el algoritmo

Escritura de archivos

La escritura de archivos consiste en guardar información en un archivo. Esto permite que los datos queden almacenados de forma permanente para usos posteriores.

Proceso general de escritura
  1. abrir el archivo en modo escritura
  2. escribir la información
  3. cerrar el archivo
Ejemplo
archivo = open("mensaje.txt", "w")
archivo.write("Hola, mundo")
archivo.close()

Este programa crea un archivo llamado mensaje.txt y escribe dentro el texto Hola, mundo.

Modo escritura y sobrescritura

Cuando un archivo se abre en modo escritura ("w"), normalmente su contenido anterior se reemplaza.

Esto significa que si el archivo ya tenía datos, estos pueden perderse al escribir de nuevo.

Ejemplo de escritura de varias líneas
archivo = open("lista.txt", "w")
archivo.write("Ana\n")
archivo.write("Carlos\n")
archivo.write("Lucía\n")
archivo.close()

Aquí se escriben varias líneas usando \n para indicar saltos de línea.

Añadir información a un archivo

En algunos casos no queremos reemplazar el contenido, sino añadir información nueva al final del archivo. Para ello se utiliza normalmente el modo de adición o append.

archivo = open("lista.txt", "a")
archivo.write("Pedro\n")
archivo.close()

Así se conserva lo que ya había y se añade una nueva línea.

Almacenamiento de datos

El procesamiento de archivos está directamente relacionado con el almacenamiento de datos. Almacenar datos significa guardarlos de manera que puedan recuperarse y utilizarse después.

Los archivos son una de las formas más básicas y accesibles de almacenamiento en programación. Antes de usar bases de datos más complejas, muchos programas simples guardan la información en archivos.

Ejemplos de datos que pueden almacenarse en archivos
  • nombres de usuarios
  • notas de exámenes
  • resultados de un programa
  • registros de errores
  • listas de tareas
  • configuraciones personalizadas
Ventaja principal

El gran valor del almacenamiento en archivos es que los datos sobreviven al cierre del programa. Esto hace posible construir aplicaciones útiles en el mundo real.

Ejemplo práctico: guardar notas

Imaginemos que queremos escribir un programa que guarde las notas de varios estudiantes en un archivo.

archivo = open("notas.txt", "w")
archivo.write("7\n")
archivo.write("8\n")
archivo.write("6\n")
archivo.write("9\n")
archivo.write("5\n")
archivo.close()

Más tarde, otro programa podría leer esas notas:

archivo = open("notas.txt", "r")

for linea in archivo:
    print(linea)

archivo.close()

Así se ve claramente cómo un programa puede guardar y otro recuperar la información.

Procesamiento de archivos y estructuras de datos

Muchas veces, la lectura de archivos se combina con el uso de listas o arrays. Por ejemplo, un programa puede leer todas las líneas de un archivo y almacenarlas en una estructura de datos para procesarlas después.

archivo = open("nombres.txt", "r")
nombres = []

for linea in archivo:
    nombres.append(linea.strip())

archivo.close()

print(nombres)

En este ejemplo:

  • el archivo se lee línea a línea
  • cada línea se añade a una lista
  • después la lista puede recorrerse, ordenarse o analizarse

Esto muestra cómo el procesamiento de archivos se conecta con otros temas del curso.

Posibles problemas al trabajar con archivos

Aunque los archivos son muy útiles, también pueden surgir dificultades:

  • el archivo puede no existir
  • puede estar vacío
  • puede contener datos mal formateados
  • puede leerse o escribirse en el modo equivocado
  • puede olvidarse cerrar el archivo

En programación real, estos problemas obligan a tomar precauciones adicionales. En este nivel, lo importante es entender que trabajar con archivos requiere cuidado, porque se está interactuando con datos almacenados fuera del programa.

Importancia de cerrar archivos

Cerrar un archivo después de usarlo es importante porque:

  • libera recursos del sistema
  • asegura que los datos se guarden correctamente
  • evita problemas de acceso posterior

Un error frecuente en principiantes es abrir archivos y no cerrarlos al terminar.

Formatos sencillos de archivos

En este nivel, normalmente se trabaja con archivos de texto porque son fáciles de leer y entender. Un archivo de texto puede contener:

  • una lista de elementos
  • números separados por líneas
  • mensajes o frases
  • registros sencillos

Más adelante, en contextos más avanzados, pueden aparecer otros formatos, pero para comprender la idea del procesamiento de archivos, el texto es suficiente y muy adecuado.

Lectura, escritura y ciclo de vida de la información

Una forma clara de entender el procesamiento de archivos es pensar en el ciclo completo de la información:

  1. un programa genera datos
  2. los guarda en un archivo
  3. otro momento posterior permite recuperar esos datos
  4. el programa los procesa y genera nueva información

Este ciclo es fundamental en muchísimas aplicaciones reales.

Ejemplo integrado

Supongamos que un profesor quiere un programa que lea las notas guardadas en un archivo, calcule la media y escriba el resultado en otro archivo.

Archivo inicial: notas.txt

7
8
6
9
5

Algoritmo general

  1. abrir el archivo de notas
  2. leer cada nota
  3. sumarlas
  4. contar cuántas hay
  5. calcular la media
  6. abrir un nuevo archivo
  7. escribir el resultado
  8. cerrar ambos archivos

Ejemplo de código

archivo = open("notas.txt", "r")
suma = 0
contador = 0

for linea in archivo:
    nota = int(linea)
    suma = suma + nota
    contador = contador + 1

archivo.close()

media = suma / contador

resultado = open("resultado.txt", "w")
resultado.write("La media es: " + str(media))
resultado.close()

Este ejemplo muestra cómo el procesamiento de archivos puede combinar lectura, cálculo y escritura de resultados.

Conceptos clave

  • Archivo: conjunto de datos almacenado de forma permanente en un dispositivo.
  • Procesamiento de archivos: uso de archivos para leer, escribir y almacenar información dentro de un programa.
  • Lectura de archivos: obtención del contenido de un archivo para utilizarlo en el programa.
  • Escritura de archivos: guardado de información en un archivo.
  • Almacenamiento de datos: conservación de información de forma persistente.
  • Modo lectura: apertura de un archivo para consultar su contenido.
  • Modo escritura: apertura de un archivo para guardar contenido nuevo.
  • Modo adición: apertura de un archivo para añadir contenido al final sin borrar lo anterior.
  • Persistencia: capacidad de conservar datos después de cerrar el programa.

Ejemplo práctico

Supongamos que un programa necesita guardar los nombres de tres estudiantes en un archivo y luego leerlos para mostrarlos en pantalla.

Escritura del archivo:

archivo = open("estudiantes.txt", "w")
archivo.write("Ana\n")
archivo.write("Carlos\n")
archivo.write("Lucía\n")
archivo.close()

Lectura del archivo:

archivo = open("estudiantes.txt", "r")

for linea in archivo:
    print(linea)

archivo.close()

Qué ocurre en este ejemplo:

  • se crea un archivo y se escriben tres nombres
  • más tarde el mismo archivo se abre en modo lectura
  • sus líneas se procesan una a una
  • los datos almacenados permanecen disponibles incluso después de cerrar el programa

Qué conceptos aparecen:

  • archivo
  • escritura
  • lectura
  • persistencia de datos
  • almacenamiento
  • procesamiento línea a línea

Aplicaciones en el mundo real

  • Plataformas educativas: guardan calificaciones, usuarios y resultados.
  • Aplicaciones de notas: almacenan listas de tareas y recordatorios.
  • Sistemas administrativos: generan archivos con informes y registros.
  • Programas de sensores: registran mediciones en archivos para analizarlas después.
  • Videojuegos: guardan partidas y puntuaciones.

En todos estos casos, los archivos permiten conservar información para usarla más tarde, algo que no sería posible si los datos solo se mantuvieran en memoria.

Errores frecuentes de los estudiantes

  • Confundir variable con archivo: la variable guarda datos temporalmente; el archivo los guarda de forma permanente.
  • Olvidar cerrar el archivo: esto puede provocar errores o impedir que los datos se guarden correctamente.
  • Abrir un archivo en el modo equivocado: por ejemplo, usar escritura cuando solo se quería leer.
  • No entender que escribir en modo "w" puede borrar el contenido anterior: esto provoca pérdida de datos.
  • Pensar que leer un archivo siempre funciona: el archivo puede no existir o tener un formato inesperado.
  • No relacionar archivos con estructuras de datos: muchos archivos se leen para cargar sus datos en listas o arrays.

Conexiones con otros temas del curso

  • B2.1 Fundamentos de programación: el procesamiento de archivos amplía la idea de entrada y salida de datos.
  • B2.2 Estructuras de datos: los datos leídos de archivos suelen almacenarse en listas o arrays.
  • B2.3 Constructos de programación: los bucles y condicionales son esenciales para procesar el contenido de los archivos.
  • B2.4 Algoritmos de programación: leer y escribir archivos requiere algoritmos bien estructurados.
  • A3 Bases de datos: los archivos son una forma sencilla de almacenamiento, mientras que las bases de datos son una solución más estructurada y potente.

Resumen

  • Un archivo es una unidad de información almacenada de forma permanente.
  • El procesamiento de archivos permite leer, escribir y almacenar datos.
  • La lectura recupera información previamente guardada.
  • La escritura permite guardar información nueva.
  • Los archivos hacen posible la persistencia de datos, es decir, conservar la información tras cerrar el programa.
  • Trabajar con archivos amplía mucho la utilidad práctica de los programas.
  • El procesamiento de archivos se relaciona estrechamente con estructuras de datos, algoritmos y estructuras de control.
