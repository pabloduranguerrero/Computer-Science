B2.2 Estructuras de datos

Pregunta guía

¿Cómo se pueden organizar varios datos dentro de un programa para almacenarlos, acceder a ellos y manipularlos de forma eficiente?

Introducción

En los fundamentos de programación vimos que una variable permite almacenar un dato individual, como un número, una palabra o un valor lógico. Sin embargo, muchos programas necesitan trabajar con conjuntos de datos, no solo con valores aislados.

Por ejemplo, una aplicación puede necesitar guardar:

  • las notas de toda una clase
  • los nombres de varios estudiantes
  • una lista de tareas pendientes
  • los productos disponibles en una tienda
  • las temperaturas registradas durante una semana

Si intentáramos guardar toda esa información usando una variable diferente para cada elemento, el programa se volvería rápidamente desordenado, difícil de ampliar y complicado de mantener.

Para resolver este problema se utilizan las estructuras de datos. Una estructura de datos es una forma de organizar varios valores dentro de un programa para poder almacenarlos, acceder a ellos y utilizarlos con mayor facilidad.

En este tema nos centraremos en las estructuras más básicas y más útiles para este nivel:

  • listas
  • arrays
  • estructuras simples de almacenamiento

El objetivo no es solo conocer su definición, sino entender por qué son necesarias, cómo se utilizan y en qué situaciones resulta más útil emplearlas que utilizar variables aisladas.

Explicación detallada

¿Qué es una estructura de datos?

Una estructura de datos es una forma organizada de almacenar varios datos dentro de un programa. Su finalidad es permitir que esos datos puedan gestionarse de manera más clara y eficiente.

En otras palabras, una estructura de datos ayuda a responder preguntas como estas:

  • ¿Cómo guardamos varios valores relacionados?
  • ¿Cómo accedemos a uno de ellos?
  • ¿Cómo recorremos todos los elementos?
  • ¿Cómo añadimos, modificamos o eliminamos datos?

La necesidad de usar estructuras de datos aparece en cuanto un programa deja de trabajar con un único valor. Por ejemplo, si queremos almacenar las notas de cinco estudiantes, no resulta práctico usar variables como:

nota1 = 7
nota2 = 8
nota3 = 6
nota4 = 9
nota5 = 5

Aunque esto puede funcionar en un ejemplo muy pequeño, se vuelve incómodo y poco flexible. ¿Qué pasaría si en lugar de cinco estudiantes hubiera treinta? ¿Y si quisiéramos calcular la media automáticamente? ¿Y si hubiera que añadir una nueva nota?

Para esas situaciones es mucho mejor utilizar una estructura de datos que guarde todas las notas juntas.

¿Por qué son importantes las estructuras de datos?

Las estructuras de datos son fundamentales porque permiten:

  • organizar información relacionada
  • trabajar con varios valores de forma conjunta
  • reducir la cantidad de variables necesarias
  • hacer programas más escalables
  • facilitar el uso de bucles y algoritmos

Sin estructuras de datos, muchos programas serían demasiado largos, repetitivos y difíciles de mantener.

Listas

Una de las estructuras de datos más comunes y útiles es la lista. Una lista es una colección ordenada de elementos que se almacenan juntos bajo un mismo nombre.

Por ejemplo:

notas = [7, 8, 6, 9, 5]

Aquí, la variable notas no guarda un único valor, sino varios números agrupados en una misma estructura.

Características de las listas
  • guardan varios elementos
  • mantienen un orden
  • cada elemento puede accederse mediante una posición
  • en muchos lenguajes, pueden modificarse fácilmente

En Python, por ejemplo, cada elemento de la lista tiene un índice o posición. Normalmente, el primer elemento ocupa la posición 0.

notas = [7, 8, 6, 9, 5]
print(notas[0])

La salida sería 7, porque ese es el primer valor de la lista.

Acceso a elementos

Podemos acceder a cualquier elemento si conocemos su posición:

nombres = ["Ana", "Carlos", "Lucía", "Pedro"]
print(nombres[2])

La salida sería Lucía.

Esto es muy útil porque permite trabajar con colecciones de datos sin tener que usar una variable distinta para cada elemento.

Modificar elementos de una lista

En muchos lenguajes, las listas permiten modificar los valores que contienen:

notas = [7, 8, 6]
notas[1] = 10
print(notas)

Ahora la lista pasaría a ser [7, 10, 6].

Añadir elementos

También suele ser posible añadir nuevos elementos:

tareas = ["estudiar", "leer"]
tareas.append("repasar")
print(tareas)

La lista ahora contendría tres tareas.

Recorrer una lista

Una de las mayores ventajas de las listas es que pueden recorrerse usando bucles. Esto permite aplicar la misma operación a todos sus elementos.

notas = [7, 8, 6, 9, 5]
for nota in notas:
    print(nota)

Este programa muestra cada nota por separado. Aquí se ve claramente por qué las estructuras de datos son tan útiles: trabajar con varios valores resulta mucho más sencillo.

Arrays

Otra estructura de datos importante es el array. En muchos contextos educativos, el array se presenta como una estructura similar a una lista, ya que también permite almacenar varios elementos bajo un mismo nombre y acceder a ellos por posición.

La idea principal de un array es que contiene una secuencia ordenada de elementos del mismo tipo.

Por ejemplo, un array de temperaturas podría almacenar:

[18, 20, 19, 21, 22]

y un array de nombres podría almacenar:

["Ana", "Carlos", "Lucía"]
Lista y array: similitudes y diferencias

En este nivel, lo más importante es entender que tanto listas como arrays sirven para almacenar varios elementos. No obstante, conceptualmente suele explicarse que:

  • una lista suele ser más flexible
  • un array suele tener una estructura más fija
  • un array suele contener elementos del mismo tipo

En muchos cursos introductorios, especialmente cuando se usa Python, la lista cumple el papel práctico que en otros lenguajes cumple el array.

Por tanto, para un estudiante de este nivel, lo más importante es comprender la idea general: se trata de estructuras que permiten guardar muchos datos relacionados y acceder a ellos mediante índices.

Índices y posiciones

Tanto en listas como en arrays, los elementos suelen identificarse por su posición. Esta posición recibe el nombre de índice.

Por ejemplo, en la lista:

colores = ["rojo", "azul", "verde"]
  • colores[0] es "rojo"
  • colores[1] es "azul"
  • colores[2] es "verde"

Comprender los índices es esencial, porque permiten acceder a datos concretos dentro de una colección.

Estructuras simples de almacenamiento

Cuando hablamos de estructuras simples de almacenamiento, nos referimos a formas básicas de guardar datos de manera organizada dentro de un programa. En este nivel, las más importantes son precisamente las estructuras lineales como listas y arrays.

Se llaman simples porque:

  • son fáciles de entender
  • los datos suelen almacenarse en secuencia
  • permiten recorrer elementos uno a uno
  • son la base para estructuras más complejas

Por ejemplo, una lista de nombres, una lista de temperaturas o una secuencia de precios son estructuras simples de almacenamiento.

Ejemplo: guardar las notas de una clase

Imaginemos que queremos almacenar las notas de cinco estudiantes y calcular la media.

notas = [7, 8, 6, 9, 5]
suma = 0

for nota in notas:
    suma = suma + nota

media = suma / len(notas)
print("La nota media es:", media)

Este ejemplo muestra varias ideas importantes:

  • las notas se guardan juntas en una estructura
  • se puede recorrer la colección con un bucle
  • se puede calcular un resultado a partir de todos los elementos

Ejemplo: lista de tareas

tareas = ["estudiar", "leer", "hacer ejercicios"]
print(tareas[0])

En este caso, la estructura de datos permite organizar varias tareas bajo una sola variable. Esto resulta mucho más práctico que usar variables separadas como tarea1, tarea2 y tarea3.

¿Cuándo conviene usar una estructura de datos?

Conviene utilizar una estructura de datos cuando:

  • hay varios valores relacionados
  • es necesario recorrer o procesar todos los elementos
  • los datos deben mantenerse agrupados
  • el número de elementos puede crecer

Por ejemplo, tendría sentido usar una lista para:

  • nombres de estudiantes
  • calificaciones
  • productos de una tienda
  • temperaturas de varios días

En cambio, si solo queremos guardar un único dato, una variable simple suele ser suficiente.

Ventajas de usar estructuras de datos

  • hacen el programa más ordenado
  • permiten agrupar información relacionada
  • facilitan el uso de bucles
  • evitan la repetición innecesaria de variables
  • preparan al estudiante para estructuras más avanzadas

Limitaciones y cuidados

Aunque son muy útiles, las estructuras de datos también exigen cuidado. Algunos errores comunes son:

  • usar un índice incorrecto
  • intentar acceder a una posición que no existe
  • confundir el valor con la posición
  • no entender qué tipo de datos contiene la estructura

Por eso es importante practicar no solo la definición, sino también el uso real de estas estructuras en pequeños programas.

Conceptos clave

  • Estructura de datos: forma organizada de almacenar varios datos en un programa.
  • Lista: colección ordenada de elementos almacenados bajo un mismo nombre.
  • Array: estructura ordenada de elementos, normalmente del mismo tipo, accesibles por posición.
  • Índice: posición de un elemento dentro de una lista o array.
  • Colección: conjunto de varios elementos agrupados en una estructura.
  • Recorrer: acceder a los elementos de una estructura uno a uno.
  • Almacenamiento secuencial: organización lineal de los datos dentro de una estructura.

Ejemplo práctico

Supongamos que un profesor quiere almacenar las notas de varios estudiantes y calcular la media del grupo.

notas = [7, 8, 6, 9, 5]
suma = 0

for nota in notas:
    suma = suma + nota

media = suma / len(notas)
print("La media de la clase es:", media)

Qué ocurre en este programa:

  • se almacenan varias notas en una lista
  • se recorre la lista con un bucle
  • se suman todos los valores
  • se calcula la media usando el número total de elementos
  • se muestra el resultado final

Qué conceptos aparecen aquí:

  • estructura de datos
  • lista
  • índice implícito o recorrido secuencial
  • almacenamiento de varios datos relacionados
  • uso conjunto con algoritmos y bucles

Aplicaciones en el mundo real

  • Educación: listas de estudiantes, notas, tareas o asistencias.
  • Comercio electrónico: productos disponibles, precios y cantidades.
  • Aplicaciones móviles: listas de mensajes, contactos o recordatorios.
  • Videojuegos: puntuaciones, vidas, enemigos o posiciones.
  • Sensores y robótica: almacenamiento de mediciones tomadas en distintos momentos.

En todos estos contextos, los programas necesitan trabajar con varios datos relacionados, y por eso las estructuras de datos son indispensables.

Errores frecuentes de los estudiantes

  • Confundir índice con valor: la posición no es lo mismo que el dato almacenado.
  • Pensar que el primer índice es 1: en muchos lenguajes, el primer índice es 0.
  • Intentar acceder a posiciones inexistentes: esto produce errores.
  • No ver la utilidad de las estructuras de datos: usar muchas variables separadas suele ser peor.
  • Confundir lista con variable simple: una lista contiene varios elementos, no uno solo.
  • No relacionar estructuras de datos con bucles: muchas veces su utilidad real aparece al recorrerlas.

Conexiones con otros temas del curso

  • B2.3 Constructos de programación: los bucles y condicionales permiten trabajar con los elementos de una estructura.
  • B2.4 Algoritmos de programación: muchos algoritmos procesan listas o arrays.
  • B2.5 Procesamiento de archivos: los datos leídos de archivos suelen almacenarse en estructuras.
  • A3 Bases de datos: aunque una base de datos es distinta de una lista, ambas organizan información de manera estructurada.

Resumen

  • Las estructuras de datos permiten almacenar varios datos de forma organizada.
  • Las listas y los arrays son ejemplos básicos de estructuras de datos.
  • Estas estructuras agrupan varios valores bajo un mismo nombre.
  • Cada elemento suele identificarse mediante un índice o posición.
  • Las estructuras de datos facilitan el uso de bucles, algoritmos y programas más escalables.
  • Son esenciales cuando un programa trabaja con conjuntos de datos relacionados.
