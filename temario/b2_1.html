B2.1 Fundamentos de programación

Pregunta guía

¿Cómo se construyen los programas informáticos a partir de instrucciones, datos y operaciones básicas que permiten resolver problemas de forma lógica y automática?

Introducción

La programación es uno de los pilares de la informática. Gracias a ella, los dispositivos digitales pueden ejecutar instrucciones, procesar información y realizar tareas de manera automática. Cada vez que una persona usa una aplicación móvil, una página web, un videojuego, una calculadora o un sistema de gestión, detrás existe un programa que ha sido diseñado para responder a unas necesidades concretas.

Sin embargo, aprender a programar no consiste solo en memorizar comandos o copiar fragmentos de código. Lo más importante al principio es comprender cómo piensa un programa, cómo se organiza la información dentro de él y cómo se construyen las instrucciones que le permiten actuar.

En este sentido, los fundamentos de programación son la base sobre la que se apoya todo lo demás. Antes de estudiar estructuras de control más complejas, algoritmos avanzados o programación orientada a objetos, es necesario comprender bien algunos conceptos esenciales:

  • qué es un programa
  • qué es una instrucción
  • qué es una variable
  • qué tipos de datos existen
  • cómo recibe datos un programa
  • cómo produce resultados

Estos conceptos aparecen en prácticamente todos los lenguajes de programación. Aunque la sintaxis de Python, Java o JavaScript no sea exactamente igual, la lógica fundamental que hay detrás es muy parecida.

Por eso, estudiar B2.1 no significa solo aprender unos contenidos iniciales, sino construir una base sólida que permitirá entender el resto de la programación con mayor seguridad.

Explicación detallada

1. ¿Qué es un programa?

Un programa es un conjunto de instrucciones escritas en un lenguaje de programación que indican a un ordenador qué debe hacer.

Estas instrucciones se organizan de manera lógica y se ejecutan en un cierto orden para resolver una tarea concreta. Esa tarea puede ser muy simple, como mostrar un mensaje en pantalla, o muy compleja, como gestionar una red social, procesar pagos bancarios o controlar un robot.

Idea fundamental

Un ordenador no entiende objetivos generales del tipo “calcula esto” o “ordena esa información” del mismo modo que lo haría una persona. Para poder actuar, necesita recibir instrucciones claras, precisas y sin ambigüedades.

Por ejemplo, si queremos que el ordenador calcule la media de dos números, no basta con decir “haz la media”. Es necesario definir el proceso paso a paso:

  1. leer el primer número
  2. leer el segundo número
  3. sumar ambos valores
  4. dividir entre 2
  5. mostrar el resultado

Ese conjunto de instrucciones constituye la base del programa.

Ejemplo básico

Un programa muy simple puede ser:

print("Hola")

Este código muestra un mensaje en pantalla. Aunque sea un ejemplo mínimo, ya es un programa, porque contiene una instrucción que el ordenador puede ejecutar.

Características de un programa

Todo programa tiene, en mayor o menor medida, las siguientes características:

  • contiene instrucciones
  • utiliza datos
  • realiza un proceso
  • produce una salida o resultado
  • responde a un objetivo concreto
Programa y algoritmo

Es importante distinguir entre algoritmo y programa.

Un algoritmo es una secuencia lógica de pasos para resolver un problema.

Un programa es la implementación de ese algoritmo en un lenguaje de programación real.

Ejemplo

Algoritmo

  1. pedir dos números
  2. sumarlos
  3. mostrar el resultado

Programa en Python

a = int(input("Introduce el primer número: "))
b = int(input("Introduce el segundo número: "))
resultado = a + b
print(resultado)

Por tanto, el algoritmo es la idea estructurada de la solución, mientras que el programa es su traducción a un lenguaje ejecutable.

2. Las instrucciones

Un programa está formado por instrucciones. Una instrucción es una orden concreta que el ordenador debe ejecutar.

Las instrucciones pueden servir para:

  • guardar datos
  • pedir datos al usuario
  • realizar cálculos
  • comparar valores
  • mostrar mensajes
  • controlar el flujo del programa
Ejemplo
x = 10

Esta instrucción indica que el valor 10 se guarde en una variable llamada x.

print(x)

Esta otra instrucción indica que se muestre en pantalla el valor de x.

Secuencia de ejecución

En un programa sencillo, las instrucciones suelen ejecutarse en orden, de arriba hacia abajo.

Por ejemplo:

x = 10
y = 5
resultado = x + y
print(resultado)

El orden de ejecución es:

  1. guardar 10 en x
  2. guardar 5 en y
  3. calcular la suma
  4. mostrar el resultado

Si se alterara este orden, el programa podría dar un resultado distinto o incluso producir un error.

Importancia del orden

En programación, el orden importa mucho. A diferencia de otras formas de expresión más flexibles, un programa necesita una estructura concreta para funcionar correctamente.

Por ejemplo, no tendría sentido intentar mostrar el valor de una variable antes de haberla definido.

3. Variables

Una variable es un espacio de memoria con nombre que se utiliza para almacenar un dato.

Es uno de los conceptos más importantes de toda la programación, porque permite que un programa pueda guardar información y trabajar con ella.

Explicación intuitiva

Una variable puede imaginarse como una caja etiquetada:

  • la etiqueta es el nombre de la variable
  • dentro de la caja se guarda el valor

Por ejemplo:

edad = 16

Aquí:

  • edad es la variable
  • 16 es el valor almacenado
¿Por qué se llaman variables?

Porque el valor que contienen puede cambiar durante la ejecución del programa.

Ejemplo:

puntos = 10
puntos = 15

Primero puntos vale 10. Después pasa a valer 15.

Asignación

Cuando escribimos:

x = 7

estamos realizando una asignación. En programación, el signo = no suele significar igualdad matemática, sino “guardar este valor en esta variable”.

Esto es importante porque muchos estudiantes al principio interpretan mal ese símbolo.

Reasignación

Una misma variable puede recibir un nuevo valor más adelante:

contador = 1
contador = contador + 1

Tras ejecutar la segunda línea, contador valdrá 2.

Esto tiene sentido en programación porque significa:

  1. tomar el valor actual de contador
  2. sumarle 1
  3. guardar el nuevo valor en la misma variable
Ejemplos de variables
nombre = "Ana"
edad = 17
altura = 1.68
aprobado = True

Cada variable puede almacenar un tipo de información diferente.

Nombres de variables

Los nombres de las variables deben ser claros y significativos.

Es preferible escribir:

nota_media = 8.5

que algo como:

x = 8.5

salvo que el contexto sea muy evidente.

Buenas prácticas

Conviene que los nombres:

  • indiquen bien qué almacenan
  • no sean ambiguos
  • no lleven espacios
  • no empiecen por números
  • no sean palabras reservadas del lenguaje
Importancia de las variables

Las variables permiten:

  • guardar información
  • reutilizar datos
  • modificar valores
  • hacer cálculos
  • construir programas dinámicos e interactivos

Sin variables, la programación sería muy limitada y repetitiva.

4. Tipos de datos

Los tipos de datos indican qué clase de información se guarda en una variable y cómo puede utilizarse.

No todos los datos se comportan igual. Un número, un texto o un valor lógico no funcionan del mismo modo, y por eso es importante distinguirlos.

Tipos de datos básicos
4.1 Enteros

Los enteros son números sin parte decimal.

Ejemplos:

  • 5
  • 0
  • -3
  • 120

En Python se representan como int.

Ejemplo:

edad = 17
4.2 Reales o decimales

Los números con parte decimal se usan cuando hace falta más precisión.

Ejemplos:

  • 3.5
  • 7.25
  • 19.99

En Python se representan como float.

Ejemplo:

precio = 19.99
altura = 1.72
4.3 Cadenas de texto

Una cadena es una secuencia de caracteres.

Ejemplos:

  • "Hola"
  • "Ana"
  • "2026"

En Python se representan como str.

Ejemplo:

nombre = "Carlos"
4.4 Booleanos

Los valores booleanos representan verdad o falsedad.

Solo pueden tener dos valores:

  • True
  • False

Ejemplo:

aprobado = True

Son muy importantes en comparaciones y en la toma de decisiones.

Diferencia entre tipos

Observa estas variables:

numero = 10
texto = "10"
decimal = 10.0
estado = True

Aunque algunas se parezcan, no son lo mismo:

  • 10 es entero
  • "10" es texto
  • 10.0 es decimal
  • True es booleano
¿Por qué es importante el tipo?

Porque el tipo determina:

  • qué operaciones pueden hacerse
  • cómo se interpreta el valor
  • qué resultado produce el programa

Por ejemplo:

a = 5
b = 3
print(a + b)

da 8.

Pero:

a = "5"
b = "3"
print(a + b)

puede dar "53" porque está uniendo textos.

Conversión de tipos

A veces es necesario transformar un dato de un tipo a otro.

Ejemplo:

edad_texto = input("Introduce tu edad: ")
edad_numero = int(edad_texto)

Aquí el valor introducido se recibe como texto y luego se convierte a entero.

Esto es fundamental porque muchos datos de entrada se reciben inicialmente como cadenas.

5. Entrada de datos

La entrada es la información que recibe un programa para poder trabajar con ella.

Un programa puede recibir datos de distintas fuentes:

  • teclado
  • ratón
  • archivo
  • sensores
  • Internet
  • bases de datos

En programación básica, la forma más habitual es el teclado.

Ejemplo
nombre = input("Introduce tu nombre: ")

El programa pide al usuario que introduzca un texto y lo guarda en la variable nombre.

Importancia de la entrada

La entrada permite que el programa sea interactivo. Gracias a ella, el usuario puede influir en el comportamiento del programa.

Sin entrada, muchos programas serían fijos y solo podrían repetir siempre lo mismo.

Ejemplo práctico
nota1 = float(input("Introduce la primera nota: "))
nota2 = float(input("Introduce la segunda nota: "))
media = (nota1 + nota2) / 2
print(media)

Este programa no tiene valores fijos. Funciona con los datos que introduzca la persona usuaria.

Entrada y errores

Una dificultad importante es que el usuario puede introducir datos incorrectos.

Por ejemplo:

  • escribir una palabra cuando se espera un número
  • dejar un campo vacío
  • introducir un formato inesperado

En programación real esto obliga a validar la entrada, aunque en este nivel lo más importante es comprender que la entrada debe tratarse con cuidado.

6. Salida de datos

La salida es la información que el programa muestra o produce como resultado.

La salida puede presentarse de muchas formas:

  • texto en pantalla
  • un archivo
  • un gráfico
  • una señal para otro dispositivo
  • un mensaje visual o sonoro

En programación básica, normalmente la salida aparece en pantalla.

Ejemplo
print("Hola")

Muestra un mensaje.

Ejemplo con variables
nombre = "Ana"
print(nombre)

Muestra el valor almacenado.

Ejemplo con cálculo
a = 6
b = 4
resultado = a + b
print(resultado)

La salida es 10.

Importancia de la salida

La salida es necesaria porque permite que el usuario conozca el resultado del proceso realizado por el programa.

Un programa puede hacer cálculos internamente, pero si no comunica el resultado, su utilidad es muy limitada.

7. Relación entre entrada, proceso y salida

Una forma muy clara de entender los programas es mediante este esquema:

Entrada → Proceso → Salida

Entrada

Son los datos que recibe el programa.

Proceso

Son las operaciones que realiza con esos datos.

Salida

Es el resultado final.

Ejemplo: calcular el área de un rectángulo

Entrada

  • base
  • altura

Proceso

  • multiplicar base por altura

Salida

  • área

Código:

base = float(input("Introduce la base: "))
altura = float(input("Introduce la altura: "))
area = base * altura
print("El área es:", area)

Este modelo es muy útil porque ayuda al alumnado a analizar cualquier programa de forma estructurada.

8. Expresiones y operadores básicos

Una expresión es una combinación de valores, variables y operadores que produce un resultado.

Ejemplos:

3 + 4
edad + 1
Operadores aritméticos básicos
  • + suma
  • - resta
  • * multiplicación
  • / división
  • // división entera
  • % resto
  • ** potencia
Ejemplo
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000

Estos operadores permiten que los programas transformen datos y generen nueva información.

9. Ejemplos completos

Ejemplo 1: media de dos notas
nota1 = float(input("Introduce la primera nota: "))
nota2 = float(input("Introduce la segunda nota: "))
media = (nota1 + nota2) / 2
print("La nota media es:", media)
Qué ocurre aquí
  • se reciben dos datos
  • se convierten a decimal
  • se calcula la media
  • se muestra el resultado
Qué conceptos aparecen
  • programa
  • variables
  • tipos de datos
  • entrada
  • salida
  • operadores
Ejemplo 2: edad el año que viene
edad = int(input("Introduce tu edad actual: "))
edad_futura = edad + 1
print("El año que viene tendrás", edad_futura, "años.")
Qué aprende el alumno aquí
  • que la entrada suele recibirse como texto
  • que puede ser necesario convertirla
  • que una variable puede usarse para calcular otra
  • que la salida puede combinar texto y datos
Ejemplo 3: cálculo de precio con IVA
precio_base = float(input("Introduce el precio sin IVA: "))
precio_final = precio_base * 1.21
print("El precio final es:", precio_final)
Qué conceptos refuerza
  • uso de variables significativas
  • tratamiento de decimales
  • cálculo matemático
  • relación entre entrada, proceso y salida

10. Errores frecuentes de los estudiantes

1. Confundir variable con valor

La variable no es el dato, sino el nombre que lo referencia.

2. Interpretar = como igualdad matemática

En programación suele significar asignación.

3. No diferenciar entre número y texto

5 y "5" no son iguales.

4. Elegir nombres de variables poco claros

Esto hace el programa difícil de leer y entender.

5. Olvidar la conversión de tipos

Especialmente en entradas de teclado.

6. No comprender el flujo entrada → proceso → salida

Muchos errores se deben a no tener claro qué entra, qué se calcula y qué se muestra.

11. Aplicaciones en el mundo real

Los fundamentos de programación aparecen en prácticamente todos los sistemas informáticos:

  • calculadoras
  • formularios de registro
  • videojuegos
  • apps móviles
  • robots
  • sistemas de reservas
  • plataformas de aprendizaje

Por ejemplo:

  • una calculadora recibe números, opera con ellos y muestra el resultado
  • una app de notas guarda datos en variables y los presenta en pantalla
  • un robot recibe datos de sensores, procesa información y genera acciones

Aunque estos sistemas sean mucho más complejos que los ejemplos iniciales, todos utilizan estos fundamentos.

Conceptos clave

  • Programa: conjunto de instrucciones que el ordenador ejecuta para resolver una tarea.
  • Instrucción: orden concreta que el programa debe ejecutar.
  • Algoritmo: secuencia lógica de pasos para resolver un problema.
  • Variable: espacio de memoria con nombre que almacena un dato.
  • Asignación: operación mediante la cual se guarda un valor en una variable.
  • Tipo de dato: clase de información almacenada, como entero, decimal, texto o booleano.
  • Entrada: información que recibe el programa.
  • Salida: información que el programa muestra o produce como resultado.
  • Expresión: combinación de valores, variables y operadores que produce un resultado.

Ejemplo práctico

Supongamos que queremos crear un programa que calcule la media de dos exámenes.

nota1 = float(input("Introduce la primera nota: "))
nota2 = float(input("Introduce la segunda nota: "))
media = (nota1 + nota2) / 2
print("La nota media es:", media)

Qué ocurre en este programa:

  • se piden al usuario dos notas
  • las entradas se convierten a números decimales
  • se calcula la media aritmética
  • se muestra el resultado en pantalla

Qué conceptos aparecen aquí:

  • programa
  • variables
  • tipos de datos
  • entrada
  • salida
  • operadores
  • modelo entrada → proceso → salida

Aplicaciones en el mundo real

  • Calculadoras: reciben números, realizan operaciones y muestran resultados.
  • Formularios web: reciben datos del usuario y los almacenan o validan.
  • Videojuegos: guardan puntuaciones, posiciones y estados del juego en variables.
  • Apps móviles: procesan datos de entrada y generan salidas visuales o sonoras.
  • Robótica: los sistemas leen sensores, procesan información y actúan en consecuencia.

Aunque los programas reales sean mucho más complejos, todos dependen de estas ideas básicas.

Errores frecuentes de los estudiantes

  • Confundir variable con valor: una variable no es el dato en sí, sino el nombre que lo referencia.
  • Pensar que "=" significa igualdad matemática: en programación normalmente significa asignación.
  • No distinguir entre número y texto: 5 y "5" no son lo mismo.
  • Usar nombres poco claros: dificulta la comprensión del programa.
  • Olvidar convertir tipos: los datos introducidos por teclado suelen llegar como texto.
  • No entender el flujo entrada-proceso-salida: esto provoca muchos errores de razonamiento.

Resumen

  • Un programa es un conjunto de instrucciones que el ordenador ejecuta para resolver una tarea.
  • Las instrucciones son órdenes concretas que el programa sigue.
  • Las variables permiten almacenar datos con un nombre.
  • Los tipos de datos indican qué clase de información se guarda.
  • La entrada proporciona datos al programa.
  • La salida muestra o devuelve resultados.
  • Muchos programas pueden entenderse como un proceso de entrada → proceso → salida.
  • Estos fundamentos son la base de toda la programación posterior.
