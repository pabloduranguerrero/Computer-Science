B2.3 Constructos de programación

Pregunta guía

¿Cómo controlan los programas el orden en que se ejecutan las instrucciones para tomar decisiones, repetir acciones y resolver problemas de forma flexible?

Introducción

En los fundamentos de programación vimos que un programa está formado por instrucciones que normalmente se ejecutan de arriba hacia abajo. Sin embargo, un programa real necesita hacer mucho más que seguir siempre una secuencia fija. A veces debe decidir entre varias opciones, repetir una acción varias veces o detener un proceso cuando se cumple una determinada condición.

Por ejemplo, una aplicación puede necesitar:

  • mostrar un mensaje distinto según la nota obtenida por el alumno
  • repetir una acción mientras queden elementos por procesar
  • detener una operación si aparece un error
  • recorrer una lista completa de datos

Para hacer todo esto, los lenguajes de programación utilizan los llamados constructos de programación, también conocidos como estructuras de control. Son mecanismos que permiten controlar el flujo de ejecución del programa.

En este tema nos centraremos en tres ideas fundamentales:

  • secuencia
  • selección
  • iteración

Estas tres estructuras aparecen constantemente en programación y constituyen una base esencial para construir algoritmos y programas útiles.

Explicación detallada

¿Qué son los constructos de programación?

Los constructos de programación son estructuras que permiten controlar cómo se ejecutan las instrucciones dentro de un programa.

Un programa no siempre debe hacer exactamente lo mismo en el mismo orden. A veces necesita:

  • seguir una secuencia fija
  • tomar decisiones
  • repetir instrucciones

Esas posibilidades se organizan a través de los constructos básicos del control de flujo.

1. Secuencia

La secuencia es la forma más simple de ejecución. Consiste en ejecutar las instrucciones una detrás de otra, en el orden en que aparecen en el programa.

Es el flujo natural de un programa cuando no hay decisiones ni repeticiones.

Ejemplo
nombre = input("Introduce tu nombre: ")
edad = int(input("Introduce tu edad: "))
print("Hola", nombre)
print("Tu edad es", edad)

En este programa:

  1. se pide el nombre
  2. se pide la edad
  3. se muestra un saludo
  4. se muestra la edad

Las instrucciones se ejecutan en orden, sin saltos ni repeticiones.

Importancia de la secuencia

Aunque pueda parecer sencilla, la secuencia es fundamental porque todo programa está construido a partir de instrucciones ordenadas. Incluso cuando usamos condicionales y bucles, dentro de ellos sigue habiendo secuencias de pasos.

Error frecuente

Un error muy común es no prestar atención al orden de las instrucciones. Si se intenta usar una variable antes de asignarle un valor, el programa puede fallar o producir un resultado incorrecto.

2. Selección

La selección permite que el programa tome decisiones. Es decir, permite ejecutar unas instrucciones u otras según se cumpla o no una condición.

Gracias a la selección, un programa puede adaptarse a distintas situaciones.

Idea básica

La selección responde a una pregunta del tipo:

Si ocurre esto, haz una cosa; si no, haz otra.

Condiciones

Para tomar decisiones, el programa necesita evaluar una condición. Una condición es una expresión que puede dar como resultado True o False.

Ejemplos de condiciones:

edad >= 18
nota >= 5
temperatura < 0
Selección simple: if

La forma más básica de selección consiste en ejecutar una acción solo si se cumple una condición.

edad = int(input("Introduce tu edad: "))

if edad >= 18:
    print("Eres mayor de edad")

Si la condición es verdadera, se ejecuta el bloque de instrucciones. Si es falsa, el programa continúa sin ejecutar ese bloque.

Selección doble: if-else

Muchas veces no basta con decidir si se ejecuta una instrucción o no. A veces queremos elegir entre dos caminos posibles.

nota = float(input("Introduce tu nota: "))

if nota >= 5:
    print("Has aprobado")
else:
    print("Has suspendido")

Aquí el programa siempre ejecuta una de las dos opciones.

Selección múltiple: if-elif-else

También es posible que haya más de dos opciones. En ese caso, podemos usar varias condiciones encadenadas.

nota = float(input("Introduce tu nota: "))

if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

El programa comprueba las condiciones en orden y ejecuta el primer bloque cuya condición sea verdadera.

Importancia de la selección

La selección es esencial porque permite crear programas que reaccionan a situaciones distintas. Sin ella, los programas serían rígidos y solo podrían seguir siempre un camino fijo.

Aplicaciones comunes de la selección
  • validar contraseñas
  • clasificar calificaciones
  • comprobar si hay stock disponible
  • detectar errores
  • mostrar diferentes mensajes según el caso
Error frecuente

Un error habitual es escribir condiciones mal planteadas o no comprender bien qué valores hacen que una condición sea verdadera o falsa.

3. Iteración

La iteración consiste en repetir una o varias instrucciones varias veces.

Es una idea fundamental porque muchas tareas informáticas requieren repetición: recorrer listas, pedir datos varias veces, repetir cálculos, procesar registros o esperar hasta que ocurra algo.

Idea básica

La iteración responde a una pregunta del tipo:

Repite estas instrucciones mientras ocurra algo o durante un cierto número de veces.

Bucles

La iteración suele implementarse mediante bucles. Los dos tipos más habituales en programación básica son:

  • while
  • for
Bucle while

El bucle while repite un bloque de instrucciones mientras una condición sea verdadera.

contador = 1

while contador <= 5:
    print(contador)
    contador = contador + 1

Este programa muestra los números del 1 al 5.

La condición se comprueba antes de cada repetición. Cuando deja de cumplirse, el bucle termina.

Importancia del control en while

Es muy importante que en algún momento la condición deje de ser verdadera. Si no ocurre, el programa entrará en un bucle infinito.

Ejemplo de riesgo:

contador = 1

while contador <= 5:
    print(contador)

Aquí el valor de contador nunca cambia, por lo que la condición seguirá siendo siempre verdadera.

Bucle for

El bucle for se utiliza normalmente para recorrer elementos de una estructura o repetir una acción un número determinado de veces.

for i in range(5):
    print(i)

Este programa muestra una secuencia de valores. En Python, range(5) genera los valores 0, 1, 2, 3 y 4.

Recorrido de listas con for

Una aplicación muy común del bucle for es recorrer los elementos de una lista.

nombres = ["Ana", "Carlos", "Lucía"]

for nombre in nombres:
    print(nombre)

Esto permite trabajar con todos los elementos de una estructura sin tener que escribir una instrucción distinta para cada uno.

Diferencia general entre while y for
  • while se usa cuando la repetición depende de una condición.
  • for se usa cuando queremos repetir algo un número conocido de veces o recorrer una colección.
Importancia de la iteración

Sin iteración, muchos programas tendrían que repetir el mismo código una y otra vez. Los bucles hacen que los programas sean más compactos, más claros y más potentes.

Secuencia, selección e iteración juntas

En la práctica, los programas reales combinan estos tres constructos continuamente.

Por ejemplo, supongamos un programa que quiere procesar varias notas:

  • usa secuencia para leer los datos y mostrar resultados
  • usa iteración para recorrer todas las notas
  • usa selección para decidir si cada nota es aprobada o suspendida
notas = [4, 7, 6, 3, 9]

for nota in notas:
    if nota >= 5:
        print(nota, "Aprobado")
    else:
        print(nota, "Suspenso")

Este pequeño programa combina las tres ideas fundamentales del control de flujo.

Bloques de código e indentación

En muchos lenguajes, especialmente en Python, los constructos de programación organizan las instrucciones en bloques.

En Python, esos bloques se indican mediante la indentación, es decir, dejando un espacio o tabulación al inicio de las líneas que pertenecen al bloque.

if edad >= 18:
    print("Mayor de edad")
    print("Puede registrarse")

Ambas instrucciones forman parte del mismo bloque asociado al if.

Importancia de la indentación

La indentación no es solo una cuestión estética. En Python determina la estructura del programa. Una mala indentación puede cambiar el significado del código o producir errores.

Constructos y algoritmos

Los constructos de programación están muy relacionados con el diseño de algoritmos. De hecho, la mayoría de los algoritmos básicos pueden expresarse usando estas tres estructuras:

  • secuencia
  • selección
  • iteración

Esto significa que un programador debe dominar estos constructos antes de abordar problemas más complejos.

Ejemplo integrado

Supongamos que queremos crear un programa que permita introducir varias calificaciones y decir si cada una está aprobada o suspendida.

cantidad = int(input("¿Cuántas notas quieres introducir? "))

for i in range(cantidad):
    nota = float(input("Introduce una nota: "))

    if nota >= 5:
        print("Aprobado")
    else:
        print("Suspenso")

En este ejemplo:

  • hay secuencia porque las instrucciones siguen un orden
  • hay iteración porque se repite el proceso varias veces
  • hay selección porque se decide qué mensaje mostrar según la nota

Conceptos clave

  • Constructo de programación: estructura que controla cómo se ejecutan las instrucciones de un programa.
  • Estructura de control: otra forma de referirse a los constructos que organizan el flujo de ejecución.
  • Secuencia: ejecución ordenada de instrucciones una detrás de otra.
  • Selección: estructura que permite tomar decisiones según una condición.
  • Condición: expresión que puede evaluarse como verdadera o falsa.
  • Iteración: repetición de instrucciones varias veces.
  • Bucle: estructura que permite repetir un bloque de código.
  • while: bucle que repite mientras una condición sea verdadera.
  • for: bucle que recorre una secuencia o repite un número de veces.
  • Indentación: forma de organizar bloques de código, especialmente importante en Python.

Ejemplo práctico

Supongamos que un profesor quiere recorrer una lista de notas y mostrar si cada estudiante ha aprobado o suspendido.

notas = [4, 7, 6, 3, 9]

for nota in notas:
    if nota >= 5:
        print(nota, "Aprobado")
    else:
        print(nota, "Suspenso")

Qué ocurre en este programa:

  • se usa una lista con varias notas
  • el bucle for recorre cada una
  • la estructura if-else decide qué mensaje mostrar
  • la salida cambia según el valor de cada nota

Qué conceptos aparecen aquí:

  • secuencia
  • selección
  • iteración
  • condición
  • bucle
  • estructura de control

Aplicaciones en el mundo real

  • Formularios online: usan selección para validar datos y mostrar mensajes de error o confirmación.
  • Videojuegos: usan bucles para actualizar continuamente el estado del juego.
  • Apps educativas: repiten preguntas, corrigen respuestas y muestran resultados según el rendimiento.
  • Sistemas de cajero automático: toman decisiones según el saldo o el tipo de operación.
  • Robótica: repiten lecturas de sensores y reaccionan según diferentes condiciones.

Estos sistemas funcionan correctamente porque controlan el flujo del programa mediante secuencia, selección e iteración.

Errores frecuentes de los estudiantes

  • No distinguir entre secuencia, selección e iteración: cada una cumple una función distinta.
  • Plantear mal las condiciones: si la condición es incorrecta, la decisión del programa también lo será.
  • Crear bucles infinitos: ocurre cuando la condición de un while nunca deja de cumplirse.
  • Confundir for y while: ambos repiten, pero no se usan exactamente en las mismas situaciones.
  • Problemas de indentación: en Python, una indentación incorrecta cambia el bloque de instrucciones o produce errores.
  • No analizar el flujo completo del programa: algunos estudiantes leen instrucciones aisladas y no entienden cómo interactúan entre sí.

  • B2.2 Estructuras de datos: los bucles suelen utilizarse para recorrer listas y arrays.
  • B2.4 Algoritmos de programación: la mayoría de los algoritmos se expresan usando secuencia, selección e iteración.
  • B2.5 Procesamiento de archivos: al leer archivos se repiten operaciones y se toman decisiones según el contenido.
  • B3 Programación orientada a objetos: aunque cambie el estilo de programación, los constructos de control siguen siendo esenciales.

Resumen

  • Los constructos de programación controlan cómo se ejecutan las instrucciones en un programa.
  • La secuencia ejecuta instrucciones en orden.
  • La selección permite tomar decisiones según condiciones.
  • La iteración permite repetir instrucciones.
  • Los condicionales más comunes son if, if-else e if-elif-else.
  • Los bucles más comunes son while y for.
  • Estas estructuras son esenciales para que los programas sean flexibles, dinámicos y útiles.
